# Common utilities

`hashing.py`: streaming SHA256. `validation.py`: finite numeric shapes/scalars and strict integer solution parsing. `provenance.py` records read-only Git/source/environment identity and normalizes common GitHub HTTPS/SSH remote forms. `result_schema.py` writes strict per-instance JSON, records rollout-bracketing timestamps and explicit amortized runtime semantics, and requires all four objective/feasibility gates for `LOCAL_VERIFIED`. Problem-specific constraints live under problems/. No shared baseline TensorDict adapter.
